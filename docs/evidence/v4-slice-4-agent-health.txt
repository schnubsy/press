HONEST-DEGRADE BEHAVIOR
------------------------
The two new views (press_agent_health_public and press_agent_runs_daily_all_public)
do not exist in Supabase yet — they are created by a Cowork migration in a later slice.

Observed behavior when views are absent:
  - The fetch throws (non-200 response from Supabase)
  - showError() is called: renders a neutral GREY verdict card
  - Text: "Can't check the agents right now" / "The status service didn't answer.
    This page shows nothing rather than a false all-clear. Try Refresh in a moment."
  - scope: "unavailable"
  - NEVER shows green. NEVER shows false health data.
  - This is CORRECT and is the expected state until the views are deployed.

If the views exist but return empty rows:
  - showEmpty() renders: "No agent data yet" (tw-note neutral card)
  - NEVER shows green.
