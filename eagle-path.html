Saturday Check-In

How this works
Each Saturday, work through this week's checklist. Goals are checkable items — open Details to change status or add notes. Heads up lists context to watch for. Escalate if lists triggers that need action right away. Goals that aren't done in their week roll forward as carried forward items; goals stuck on someone else can be blocked so they surface in the red box up top.
